Frequently Asked Questions

What if the mentor I want to learn from doesn't need my skill?
SkillBarter solves the economic Double Coincidence of Wants in two ways: teach any student on campus to earn 1 Time-Credit (HC) redeemable with any mentor, or use our 3-Way Circular Barter Ring solver (You → Peer A → Peer B → You).
How does the platform strictly prevent monetary transactions?
Our custom validation engine (js/validation.js) scans every title, description, and proposal message to block currency symbols (₹, $, €), cash/UPI offers, and identical self-swaps before DOM insertion.
Which native Browser APIs power SkillBarter?
Six native Web APIs: Web Storage API (localStorage persistence), HTML5 Canvas 2D API (certificates & physics confetti), Web Speech API (voice search), Clipboard API, FileReader API (avatar photo upload/compression), and matchMedia.
